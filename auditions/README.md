# Grandma voice comparison

Six AI-generated performance samples, created for this demo on 2026-11-04 using OpenAI Realtime and the owner's server-side API key. They compare the built-in Marin, Coral and Ballad voices on `gpt-realtime-2.1-mini` and `gpt-realtime-2.1`.

Every sample uses the same scripted lines, the same simplified ornery Brooklyn Grandma direction, normal playback speed (1.0), and the same generation settings. This is a controlled performance comparison, not a live game or tool-use test. The voice and model are named beside each recording; no winner is selected automatically.

`manifest.json` and the six MP3 files under `audio/` are the source inputs for the `/auditions` page. The MP3s are encoded from unfiltered 24 kHz mono PCM generated by the API, with no speed or pitch processing. Raw WAVs, transcripts, acknowledgements and usage receipts remain in ignored `artifacts/voice-comparison/`; no API keys or access tokens belong in this directory.

The samples use OpenAI's built-in synthetic voices. No supplied human recording or custom voice clone was used. Their availability and use remain subject to the applicable OpenAI API terms.

Run the opt-in local recorder with `VOICE_COMPARISON=1 node scripts/voice-comparison.mjs`. Recording creates paid API usage. The script bounds each sample and skips previously completed samples only when their settings and source direction match. Building or playing the saved comparison does not create AI calls.
